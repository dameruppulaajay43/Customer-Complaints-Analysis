# Customer Complaints Analysis

## Project Overview
This project analyzes customer complaints data to identify complaint trends, common issues, product-wise complaints and company response performance.

The project was completed as part of a Junior Operations Data Analyst internship assignment.

## Tools Used
- Microsoft Excel – Data cleaning and preparation
- SQL Server – Data analysis and querying
- Power BI – Interactive dashboard and visualization

## Project Workflow
1. Cleaned and standardized the original dataset in Excel.
2. Removed duplicate records and handled missing values.
3. Imported the cleaned data into SQL Server.
4. Wrote SQL queries to analyze complaint patterns and response performance.
5. Created an interactive Power BI dashboard.
6. Developed business insights and management recommendations.

## Dataset Summary
- Original records: 5,000
- Duplicate records removed: 25
- Final cleaned records: 4,975
- Open complaints: 310
- Closed complaints: 4,665

## Key Performance Indicators
- Total Complaints
- Open Complaints
- Closed Complaints
- Timely Response Rate
- Average Response Time

## Power BI Dashboard
The dashboard includes:
- Monthly complaint trends
- Complaints by financial product
- Top 10 frequently reported issues
- Timely response rate by company
- Interactive filters for date, company and financial product
